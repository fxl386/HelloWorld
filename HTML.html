Hypertext Markup Language (HTML)

Die Ersten Schritte

HTML ist der erste Schritte für eine Webside. HTML dokumente können einfach mit dem Ende".html" erstelt werden. Wiechtig ist das HTML keine Programmier Sprache ist. Mit HTML lasst sich das GRundgerüst erstellen. Einfache Texte,Überschrifften usw werden mit HTML gemacht.
HTML kann man in zwei verschiedene Kapitel unterteil. Den Head und den Body. Der Head dient Hauptsächlich für Sachen die wir als Besucher der Webside nicht direkt sehen. Darunter z.b. Titel,verbidnung zu eine Stylesheet usw.
Hier sind die wichtigsten Sachen:

meta charset=" UTF - 8" title link rel="stylesheet" type="text/css" href=""
Ermöglicht uns Sonderzeichen und Emoties korrekt darzustellen Mit title können wir einen Title auf der Titleleiste des Browser zu weisen Nutzten wir um ein externes CSS styhlesheet zu verknüpfen

Sehen wir uns Globale Attributs an

HTML-Attribute, die für alle Elemente gelten können, werden als Global Attributes bezeichnet. Sie sind standart Attribute, die das Styling von HTML-Elementen erweitern, unabhängig vom spezifischen Elementtyp.

Hier die wichtigsten Attribute:

  • id: Weist dem Element eine eindeutige Identifikation zu.
  • class: Ordnet dem Element eine oder mehrere CSS-Klassen zu.
  • style: Wendet inline CSS-Regeln direkt auf das Element an.
  • title: Definiert zusätzliche Informationen, die als Tooltip angezeigt werden.

Absolute and Relative Paths

Absolute Pfade geben den vollständigen Speicherort einer Datei an und sind unabhängig von dem Speicherort der HTML-Datei. Sie beginnen immer mit dem Protokoll (http: oder https:) und der Domain, gefolgt vom Pfad zur Datei. Diese Methode wird meistens für außstehende Datein verwendet, die sich auf einem anderen Server befinden.
Relative Pfade beschreiben den Weg zu einer Datei im Verhältnis zur aktuellen HTML-Datei. Sie sind flexibler und ermöglichen es, Projekte lokal zu testen oder zu verschieben, ohne Links anpassen zu müssen, solange die interne Ordnerstruktur erhalten bleibt. Für interne Verlinkungen innerhalb desselben Projekts sind sie der Standard.
